# cuartillos-golf-

Microsite del Club de Golf Cuartillos: una página estática (`microsite.html`) que lee los JSON de
`datos/`.

**Publicado en <https://aaguirre-nuv.github.io/cuartillos-golf-/microsite.html>**, servido por GitHub Pages desde `main`. Es el enlace que se manda por
WhatsApp y el que abre la gente para inscribirse, así que **un cambio en `datos/` no se ve ahí hasta
que se sube `CV` en `microsite.html`**.

- Contexto del repo y de los datos: [`CLAUDE.md`](CLAUDE.md)
- Reglamento de las Ligas de Clubes sin Campo 2026 (RFGM):
  [`docs/reglamento-csc-2026.md`](docs/reglamento-csc-2026.md)
